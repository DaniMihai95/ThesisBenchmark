# Privacy-Preserving AI Study Support with Local SLMs and Single-Document RAG

A thesis benchmark comparing eight quantized small language models (SLMs) on their ability to answer study questions from course PDFs, with and without single-document retrieval-augmented generation (RAG), running entirely on a standard student laptop without cloud upload.

## Research Question

> To what extent can selected 0.6B–2B quantized SLMs running locally provide accurate, complete, and document-grounded answers to study questions from source PDFs, and how does single-document RAG affect their performance?

### Sub-questions

1. Which of the selected models performs best under direct prompting and single-document RAG?
2. To what extent does single-document RAG improve or reduce answer quality, and how does this effect vary by model, domain, and question type?
3. What do document grounding, error patterns, and efficiency results suggest about the practical usefulness of local SLM-based study assistants?

---

## Methods

### Research Design

The study uses a within-subjects comparative benchmark design. Each of the eight models is tested on the same set of questions under two conditions: direct prompting without retrieval (no-RAG) and single-document retrieval-augmented generation (RAG), across three domains: biology, law, and history. This creates 48 model-condition-domain combinations. With 30 questions per domain, the full benchmark produces **1,440 model answers** in total (8 models x 2 conditions x 3 domains x 30 questions).

The independent variables are model identity, condition (RAG vs. no-RAG), and domain. The dependent variable is the automated score assigned by GPT-5o mini on a 0-10 scale, composed of grounded accuracy and completeness (0-5 each). All inference ran locally on a standard consumer laptop via Ollama, with no GPU and no internet connection during model inference.

### Data Sources

The benchmark is based on three PDFs: an openly licensed biology textbook (*Biology 2e* by OpenStax), a U.S. government legal compilation (*Basic Laws and Authorities of the National Archives and Records Administration*), and an openly licensed history textbook (*The American Yawp: A Massively Collaborative Open U.S. History Textbook, vol. 1: to 1877*). The history source is published by Stanford University Press and licensed under CC BY-SA 4.0. All documents were used for local text processing, single-document retrieval, question generation, and analysis in this non-commercial academic study. No data were collected from human participants or animals. The only data generated by the study consisted of model outputs and automated evaluation scores.

| Domain | Document | Source |
|---|---|---|
| Biology | *Biology 2e* (Clark et al., 2018) | OpenStax, CC BY 4.0 |
| Law | *Basic Laws and Authorities of NARA* (2016) | U.S. Government public domain |
| History | *The American Yawp*, vol. 1 | Stanford University Press, CC BY-SA 4.0 |

### Question Construction

Thirty study questions were constructed per domain by the author directly from the source PDFs, yielding **90 questions** in total. Questions follow the reading comprehension taxonomy of Day and Park (2005), with cognitive level assignments informed by the revised Bloom's taxonomy (Krathwohl, 2002):

| Type | Bloom's Level | Count per domain |
|---|---|---|
| Definition / Literal Retrieval | Remember | 6 |
| Reorganisation / Integration | Understand | 6 |
| Explanation / Causal | Understand / Analyse | 6 |
| Comparison / Distinction | Analyse | 6 |
| Application / Conditional | Apply | 6 |

Each question was paired with a gold reference package: a validated reference answer, supporting passages from the source PDF, and a list of 3-5 key points required for a complete answer.

All models run in their default quantized form via Ollama. Inference configuration: temperature 0.1, max 2,048 tokens, 600 s timeout, thinking mode disabled (`think=False`).

### RAG Pipeline

Standard single-document retrieve-then-read architecture:

1. PDF converted to plain text via `pypdf`
2. Text chunked into 1,000-character segments with 200-character overlap
3. Chunks embedded with `nomic-embed-text` via Ollama and cached locally
4. Retrieval via dot-product similarity; top-3 chunks inserted into prompt

Chunking parameters, embedding model, and top-k were fixed across all models and domains. The RAG prompt instructed models to answer using only the retrieved text; the no-RAG prompt asked for a concise, accurate answer, both using consistent study-assistant role framing.

### Evaluation

All 1,440 answers were scored by GPT-5o mini using a rubric-based LLM-as-a-Judge procedure:

| Dimension | Description | Scale | Conditions |
|---|---|---|---|
| Grounded accuracy | Consistent with reference answer; no unsupported claims | 0-5 | Both |
| Completeness | Covers the required key points | 0-5 | Both |
| Document grounding | Uses the retrieved passages | 0-5 | RAG only |

The **comparable total** (0-10) = grounded accuracy + completeness. Document grounding is recorded separately and not added to the total, keeping RAG and no-RAG scores directly comparable.

The evaluator also assigned an error type label from a fixed taxonomy: `none`, `hallucination`, `retrieval_ignore`, `truncation`, `confusion`, `off_topic`, `context_overflow`.

### Statistical Analysis

- **Wilcoxon signed-rank test** on paired (RAG, no-RAG) score differences; a = 0.05
- Effect sizes: Cohen's d on paired differences; rank-biserial correlation from Wilcoxon
- 95% confidence intervals via 2,000 bootstrap iterations (seed = 42)
- Tests run globally (all domains per model) and per domain (per model x domain)
- Win rates computed per model as a complementary descriptive measure
- Efficiency = average score per second of wall-clock inference time

### Hardware

ASUS Vivobook 14 OLED, Intel Core i7 Evo, 32 GB RAM, Ubuntu Linux, CPU-only (no GPU).

## Key Results

### Overall Performance

The highest absolute score was **qwen2.5:1.5b in the RAG condition: 6.88 / 10** (95% CI [6.32, 7.40]). RAG does not uniformly improve scores:

| Model | No-RAG | RAG | Delta | Wilcoxon | Cohen's d |
|---|---|---|---|---|---|
| deepseek-r1:1.5b | 3.49 | 5.39 | +1.90 | p < .001 | +0.59 |
| qwen2.5:1.5b | 6.36 | 6.88 | +0.52 | p = .110 | +0.17 |
| qwen3.5:0.8b | 5.43 | 5.83 | +0.40 | p = .326 | +0.11 |
| gemma3:1b | 5.32 | 4.80 | -0.52 | p = .298 | -0.14 |
| llama3.2:1b | 5.14 | 4.58 | -0.57 | p = .113 | -0.15 |
| qwen3:0.6b | 5.28 | 4.20 | -1.08 | p = .008 | -0.27 |
| gemma4:e2b | 6.98 | 5.44 | -1.53 | p < .001 | -0.43 |
| gemma2:2b | 7.12 | 5.32 | -1.80 | p < .001 | -0.45 |

Note: gemma2:2b and gemma4:e2b achieve the highest no-RAG scores (7.12 and 6.98), but RAG significantly hurts both.

### Domain Breakdown

Domain had a strong moderating effect on RAG benefit:

| Domain | Mean RAG Delta | Interpretation |
|---|---|---|
| Law | +0.18 | Slight average benefit; definitions are retrievable but cross-references need integration |
| History | -0.35 | Mixed; 1 model helped, 2 hurt significantly |
| Biology | -0.83 | Retrieval consistently hurts; concept-dense text requires synthesis beyond top-3 chunks |

RAG helped most in **law** and least in **biology**.

### Document Grounding

Top document grounding scores across all (model, domain) combinations (RAG condition only):

| Model | Domain | Grounding score |
|---|---|---|
| gemma4:e2b | History | 4.83 / 5 |
| qwen3.5:0.8b | History | 4.80 / 5 |
| gemma4:e2b | Biology | 4.57 / 5 |

Models faithfully followed retrieved text, but high grounding scores did not prevent score regressions, particularly in biology where retrieved chunks were insufficient for complete answers.

### Efficiency

Best score-per-second (Pareto-relevant):

| Model | Condition | Avg time (s) | Score | Pts/s |
|---|---|---|---|---|
| qwen3:0.6b | No-RAG | 2.6 | 5.28 | 2.010 |
| gemma3:1b | No-RAG | 3.6 | 5.32 | 1.461 |
| qwen2.5:1.5b | No-RAG | 6.5 | 6.36 | 0.976 |

**qwen2.5:1.5b** provides the best absolute quality; **qwen3:0.6b** leads on score-per-second.

---

## Conclusions

1. **Local SLM study assistants are technically feasible on student hardware.** The best system reached 6.88/10 entirely on CPU with no internet connection, which is promising as a supplementary tool, though not yet reliable enough for autonomous study support.

2. **RAG is not a universally beneficial addition.** It significantly helped only 1 of 8 models, significantly hurt 3, and had no significant effect on the remaining 4. Retrieval should not be treated as a default improvement.

3. **Domain matters as much as model choice.** The mean RAG delta ranged from +0.18 (law) to -0.83 (biology), a 1.01-point spread across the same pipeline and models. Textual structure of the source domain is a primary determinant of whether retrieval helps or hurts.

4. **Newer or larger does not always mean better with RAG.** gemma2:2b and gemma4:e2b scored highest without RAG, but were significantly hurt by retrieval, suggesting their parametric knowledge is disrupted by injected context.

**Practical recommendation:** use `qwen2.5:1.5b` with RAG only when document grounding is a priority (e.g. law); for biology-style concept-dense material, no-RAG with a capable model like gemma2:2b is a better starting point.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Ensure [Ollama](https://ollama.com) is running locally and pull the required models:
   ```bash
   ollama pull qwen2.5:1.5b
   ollama pull deepseek-r1:1.5b
   ollama pull llama3.2:1b
   ollama pull gemma2:2b
   ollama pull gemma3:1b
   ollama pull gemma4:e2b
   ollama pull qwen3.5:0.8b
   ollama pull qwen3:0.6b
   ollama pull nomic-embed-text
   ```

3. Configure `.env`:
   ```env
   OPENAI_API_KEY=your_key_here
   PDF_FILENAME=subject.pdf
   QUESTION_CATEGORY=subject
   ```

4. Place source PDFs in the `files/` folder (not committed, see note below).

## Usage

Run the benchmark for the category configured in `.env`:
```bash
python benchmark.py
```

Run statistical analysis and generate plots after benchmarking all domains:
```bash
python compare.py
```

To run a different domain, update `.env`:
```env
PDF_FILENAME=history.pdf
QUESTION_CATEGORY=history
```
